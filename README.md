# WorkEthiopia — Frontend

Responsive Ethiopia-focused job portal prototype built with React, Vite, Tailwind CSS v4, React Router and Lucide icons.

## Run on Windows PowerShell
```powershell
cd ethiopia-job-portal
npm.cmd install
npm.cmd run dev
```
Open the local URL shown by Vite (usually http://localhost:5173).

## Production build
```powershell
npm.cmd run build
npm.cmd run preview
```

## Pages
Home, job search and filters, job details, companies, about, career resources, FAQs, contact, login, registration, employer information, and 404.

## Important
This is frontend-only. Listings and companies are sample data. Authentication, application submission, email, and database are not connected. Saved jobs are in-memory and reset on refresh. Replace demo contact details and connect secure backend APIs before launch. Photos and Google Fonts need internet access.
